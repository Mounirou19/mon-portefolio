Combien coûte une application web ?

Chaque application est différente, le prix est donc toujours fixé sur devis, après un premier échange gratuit. Ce qui le fait varier :

  • le nombre d'écrans et de types d'utilisateurs ;
  • les règles métier : calculs, validations, workflows ;
  • les outils externes à connecter (paiement, CRM, e-mails) ;
  • le niveau de finition attendu pour une première version.

Pour maîtriser le budget, je vous propose souvent de commencer par l'essentiel, puis d'ajouter des fonctions une fois l'application utilisée pour de vrai.

Avec quelles technologies ?

Des technologies éprouvées, que beaucoup de développeurs maîtrisent : vous ne dépendez pas de moi pour la suite.

  • Interface : TypeScript, React, Tailwind
  • Serveur : Node.js (Express) ou PHP
  • Données : PostgreSQL ou MySQL
  • Hébergement : Cloudflare, Vercel ou un serveur en Europe, selon vos contraintes

Questions fréquentes

Combien de temps faut-il pour développer une application ?

Cela dépend du périmètre. Une première version utilisable prend généralement de quelques semaines à quelques mois. Le planning est fixé dans le devis, étape par étape.

Pourquoi pas un logiciel existant ou un outil no-code ?

Si un outil existant répond à votre besoin, je vous le dirai : c'est souvent moins cher. Le sur-mesure devient intéressant quand vous adaptez votre façon de travailler à l'outil au lieu de l'inverse, ou quand les abonnements s'accumulent.

Est-ce que l'application m'appartient ?

Oui. Vous recevez le code source, les accès à l'hébergement et à la base de données, et la documentation.

Pouvez-vous reprendre une application existante ?

Oui. Je commence par un audit du code pour vous dire ce qui fonctionne, ce qui pose problème et ce que coûteraient les corrections.

Et après la mise en ligne ?

Je propose une maintenance mensuelle (mises à jour, sauvegardes, corrections) et je peux faire évoluer l'application selon vos besoins. Rien n'est imposé.

Parlons de votre application.

Réponse sous 24 h en semaine. Décrivez votre besoin en quelques lignes, je vous dis ce qui est faisable, en combien de temps et pour quel prix.
